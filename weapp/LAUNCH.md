## 二、小程序后台（mp.weixin.qq.com）

### 1. 基本信息（设置 → 基本设置）
- **名称**：小偷在哪（被占用可用：小偷在哪欧洲版 / 防扒地图）
- **头像**：`brand/logo-512.png`
- **简介**（复制）：
  > 欧洲防扒地图：查看各城市有出处的扒窃、抢夺、诈骗套路记录，出发前了解哪里需要多留心；被偷后怎么办一键查看。
- **服务类目**：工具 > 信息查询

### 2. 用户隐私保护指引（设置 → 服务内容声明 → 用户隐私保护指引）
逐项勾选并填写用途：

| 信息类型 | 用途（复制） |
|---|---|
| 位置信息 | 在地图上回到你所在的位置，查看附近的已标记地点 |
| 选择的位置信息 | 上报失窃时在地图上选择发生地点 |
| 选中的照片或视频信息 | 上报或申诉时上传证据图片，仅本人和管理员可见 |
| 微信 OpenID | 区分你提交的内容，记录审查投票和喜欢，不用于其他目的 |

- 存储期限：处理完成后 180 天
- 联系方式：填你的邮箱

### 3. 接口权限（开发管理 → 接口设置）
申请 `wx.getLocation`、`wx.chooseLocation`。

- 使用场景（复制）：
  > 小偷在哪是欧洲防扒信息查询工具。用户点击地图上的「定位」按钮时获取当前位置，把地图移到用户附近，查看周边已标记的失窃地点；用户上报失窃经历时选择发生位置。仅在用户主动点击时获取，不在后台持续获取。
- 需要上传截图：首页地图（定位按钮）、上报页（选择位置）。

### 4. 小程序备案（设置 → 基本设置 → 小程序备案）
- 需要：身份证、中国大陆手机号（能收短信）、人脸核验
- 前置审批：无
- 管局审核通常 1–3 周，期间可以继续测试体验版

### 5. 代码上传安全
- 上线后到「开发管理 → 开发设置 → 小程序代码上传」**重置上传密钥**（旧密钥在对话里出现过），把新的 `private.key` 放进桌面 `xiaotou-map` 文件夹替换旧的。

## 三、云开发控制台

### 1. 数据库权限（数据库 → 每个集合 → 数据权限）
对 `places`、`reports`、`votes`、`appeals`、`likes`、`admins` 六个集合，都选「自定义安全规则」，填：
```json
{ "read": false, "write": false }
```
小程序所有读写都经过云函数，客户端不需要直接访问数据库，这样可以防止别人绕过审核直接读写。

### 2. 存储权限（存储 → 权限设置）
选「仅创建者可读写」。证据图片只有上传者本人和管理员（通过云函数）能看到。

### 3. 数据
小程序「我的」页长按底部文字 → 输入管理员邀请码 → 管理后台「数据」：先「初始化数据库」，再「同步官方数据」。

## 四、提交审核（版本管理）

1. 双击 `发布小偷在哪.bat` 上传最新代码
2. 版本管理 → 开发版「选为体验版」→ 扫码检查：首页地图和列表、详情、上报、申诉、我的
3. 「提交审核」，**审核备注**（复制）：

> 小偷在哪是面向中国出境游客的欧洲防扒信息查询工具。
> 1. 地图数据来自英国警方开放数据（data.police.uk，开放政府许可）、各国警方通报和公开媒体报道，每条记录在详情页注明出处。
> 2. 用户上报的内容和图片仅提交者本人和管理员可见；管理员人工审核后，以改写、脱敏的文字公开，不公开用户原文和图片。
> 3. 所有用户文字提交前经过微信内容安全接口检测。
> 4. 被标记的商家或场所可在「申诉」页申请复核，处理结果公示。
> 测试路径：首页默认显示伦敦，可直接查看地图标记和列表；点任一地点进入详情；点地图上的位置可体验上报流程。

4. 审核通过后点「发布」
