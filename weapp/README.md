# 小偷在哪 · 微信小程序

欧洲防扒地图的微信小程序版。页面结构和交互逻辑与「床虱地图」一致，视觉更年轻：

| 床虱地图 | 小偷在哪 |
|---|---|
| 床虱 / 蟑螂 / 其他害虫 三个开关 | 扒窃 / 抢夺 / 诈骗套路 |
| 图钉中心＝结论，外圈＝审查人数 | 同：中心图标＝类别，颜色＝谁认定的，外圈＝参与审查人数（0 / 1–2 / 3–5 / 6–10 / 11+） |
| 半蓝图钉＝被申诉 | 同：半蓝＝申诉处理中，橙色＝申诉后存疑 |
| 北京市当前区域已标记商家 N 家 | 罗马当前区域已标记地点 N 处（随地图拖动更新） |
| 酒店 / 申诉 / 我的 | 地点 / 申诉 / 我的 |
| 使用说明浮窗 + 长说明弹窗 | 同，内容换成扒窃手法、防范和被偷后处理 |
| 我的标注、我提交的证据、喜欢开发者 | 同 |
| 申诉列表「审核通过 · 管理员确认信息」 | 同 |

## 第一次跑起来（约 20 分钟）

1. **注册小程序**：mp.weixin.qq.com 注册，拿到 AppID，填进 `project.config.json` 的 `appid`。
2. **开通云开发**：开发者工具打开 `weapp/`，点「云开发」开通环境（基础版即可）。
3. **部署云函数**：右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」。
4. **设置管理员邀请码**：云开发控制台 → 云函数 → api → 函数配置 → 环境变量，新增 `ADMIN_INVITE_CODE`（至少 8 位，自己保管）。
5. **存储权限**：云开发控制台 → 存储 → 权限设置，选「仅创建者可读写」。证据图片只有上传者和管理员（经云函数）能看到。
6. **成为管理员**：在小程序「我的」页**长按底部「小偷在哪 · 共建无扒之旅」**，输入邀请码。
7. **初始化数据**：管理后台 →「数据」→ 先点「初始化数据库」，再点「同步官方数据」。地图上就会出现罗马、米兰、巴塞罗那、伦敦等城市的真实记录。
8. **建索引（建议）**：数据库 `places` 集合给 `city` 建索引；`reports`、`appeals` 给 `status`、`_openid` 建索引。

## 在中国上架要做的事

- **小程序备案**：2023 年 9 月起新上架小程序必须先完成备案（后台「设置 → 基本设置 → 小程序备案」）。
- **主体**：个人主体可以上架，但个人主体**不能公开展示用户发布的内容**。本项目已按这个限制设计：用户上报的原文和图片只有本人和管理员可见，地图上公开的是管理员改写、脱敏后的文字。商家申诉材料同样不公开（和床虱地图一样）。如果以后想公开用户原文，需要换企业主体并选择相应的社区类目。
- **服务类目**：建议选「工具 > 信息查询」。提交审核时在备注里说明「数据来源为境外警方公开数据与媒体报道，用户内容经人工审核后发布」。
- **用户隐私保护指引**：后台「设置 → 服务内容声明 → 用户隐私保护指引」，勾选：位置信息（定位、选择位置）、选中的照片、用户 OpenID。和 `pages/doc` 中的隐私政策保持一致。
- **地理位置接口**：`getLocation`、`chooseLocation` 需要在后台「开发管理 → 接口设置」申请，用途写「在地图上定位到用户所在位置、上报时选择地点」。
- **内容安全**：所有用户文字提交时都会调用微信 `msgSecCheck`，命中风险直接拒绝；所有内容还要经过管理员人工审核才会公开。
- **数据出境**：数据存储在腾讯云中国境内服务器，不调用境外接口。官方数据随云函数一起打包部署。
- **运营者信息**：填写 `miniprogram/utils/config.js` 的 `operator` 和 `contactEmail`，与后台主体信息一致。不填会显示「小偷在哪运营者」。

## 地图说明

小程序只能使用自带的 `<map>` 组件（腾讯地图）。腾讯地图在欧洲能显示道路和主要地名，但细节比国内少。上线前请在真机上打开几个城市确认底图显示正常。欧洲坐标不需要做 GCJ-02 偏移。

## 更新数据

网站仓库里的已核验数据（`data/verified-events-v21.json`、`data/verified-uk-police-areas.json`、`cities.json`）更新后：

```bash
node weapp/scripts/build-data.cjs     # 同步城市表和数据快照
```

然后重新部署云函数，在管理后台再点一次「同步官方数据」。游客上报的记录会保留。

修改图钉或 tab 图标的样式后重新生成图片：

```bash
PLAYWRIGHT=playwright-core node weapp/scripts/gen-assets.cjs
```
