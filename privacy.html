隐私与数据使用说明

最后更新：2026年10月14日 · 公开基础版

核心原则：当前版本是面向中国旅欧游客的公开旅行安全资料工具，不提供账户、不接受服务器端失窃举报、不建立嫌疑人画像。

1. 信息类型

查询城市、景点和紧急电话号码时，无需注册。用户主动创建的事件笔记仅保存于本机浏览器的 localStorage，不会发送到本网站服务器，也不会自动展示给其他人。页面允许用户在“我的记录”查看、导出和删除本机笔记。

2. 定位权限

只有点击“定位”且浏览器授权后，网站才使用位置数据平移地图。本网站的应用代码不保存该坐标、不据此生成个人档案；地图底图服务仍可能因请求而接收技术数据。

3. 外部服务与日志

默认地图基于 Leaflet 与 OpenStreetMap 在线地图瓦片；切换 Google Maps 时，浏览器会直接向 Google 发送加载请求。地图、第三方网站及托管基础设施可能按其各自政策处理 IP 地址、请求日志、Cookie 或其他技术数据。网站托管在 Vercel。您可以不启用 Google 地图，并按需要配置浏览器的隐私设置。

4. Google Maps API Key

只有您主动输入密钥时，才会将其写入本机浏览器存储，用于从浏览器直接请求 Google Maps JavaScript API。密钥会在发送地图服务请求时提供给 Google；请使用受 HTTP 来源域名和 API 类型限制的密钥。不要输入不受限的高权限密钥。

5. 内容与第三方数据

当前不处理照片、身份证件、游客账户或可识别的嫌疑人信息；请勿在本机笔记中填写联系方式、身份证号、姓名或能够识别特定个人的描述。第三方资料链接只用于跳转，并不表示对第三方内容负责或已获批量数据复用许可。

6. 删除与更新

可在“我的记录”删除所有本机笔记，或清除本网站浏览器存储。页面不提供云端备份；清除后可能无法恢复。仅本机删除不能清除地图供应商或托管服务商依法留存的日志。

7. 联系与主体披露

本公开基础版尚未启用用户账户、线上付费、服务器端投稿或广告投放。当前可通过 项目 GitHub 问题反馈报告不含个人信息的技术问题；请勿在公开问题区提交个人隐私或案件细节。运营主体与非公开隐私请求联系渠道应在开通任何个人信息收集或商业服务之前完善。

8. 更新日期
