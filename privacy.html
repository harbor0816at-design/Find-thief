隐私与数据使用说明

最后更新：2026年10月14日 · 安全上报准备版

核心原则：本网站面向中国旅欧游客，提供旅行安全资料；没有接通独立审核数据库时，丢失提醒仅保存在本机。启用线上接收且您明确同意后，报告才会进入独立数据库，仅用于失窃线索核验和区域匿名提醒，不建立嫌疑人画像。

1. 信息类型

查询城市、景点和紧急电话号码时，无需注册。用户主动创建的事件笔记仅保存于本机浏览器的 localStorage，默认不会发送到本网站服务器。若启用了线上投稿且用户明确同意，具体地址、发生日期、事件类型、经过、可选坐标将通过加密连接发送至位于欧盟区域的独立数据库，供授权审核人员审查。提交时使用经密钥哈希的网络标识和10分钟时间段防刷，不存储该功能中的原始IP地址；基础设施服务商可能依其规则记录网络日志。被批准后仅公开人工改写摘要、日期、城市和约1公里精度的示意中心点，绝不公开原始地址。页面允许用户在“我的记录”查看、导出和删除本机笔记。

2. 定位权限

只有点击“定位”且浏览器授权后，网站才使用位置数据平移地图。本网站的应用代码不保存该坐标、不据此生成个人档案；地图底图服务仍可能因请求而接收技术数据。

3. 外部服务与日志

默认地图基于 Leaflet 与 OpenStreetMap 在线地图瓦片；切换 Google Maps 时，浏览器会直接向 Google 发送加载请求。地图、第三方网站及托管基础设施可能按其各自政策处理 IP 地址、请求日志、Cookie 或其他技术数据。网站托管在 Vercel。您可以不启用 Google 地图，并按需要配置浏览器的隐私设置。

4. Google Maps API Key

只有您主动输入密钥时，才会将其写入本机浏览器存储，用于从浏览器直接请求 Google Maps JavaScript API。密钥会在发送地图服务请求时提供给 Google；请使用受 HTTP 来源域名和 API 类型限制的密钥。不要输入不受限的高权限密钥。

5. 内容与第三方数据

不提供照片上传。线上管理员账户由独立身份服务验证；游客不要求提交身份证件或可识别的嫌疑人信息。请勿在本机笔记中填写联系方式、身份证号、姓名或能够识别特定个人的描述。第三方资料链接只用于跳转，并不表示对第三方内容负责或已获批量数据复用许可。

6. 目的、依据与权利

在线提交的处理目的为接收、核验和发布匿名旅行安全提醒。游客提交时需勾选隐私说明；涉及其他个人信息或犯罪指控时不应提交。您可通过运营者公布的非公开联系渠道提出访问、更正、删除及撤回请求。撤回不会影响此前基于同意的处理合法性；公开匿名摘要如已无法关联到个人可能无法据此识别。

7. 删除与更新

可在“我的记录”删除所有本机笔记，或清除本网站浏览器存储。在线报告由工作人员管理，最长保存期限：拒绝报告30天、未处理报告90天、审核通过报告365天（按创建时间计），由每日定时任务清理。页面不提供云端备份；清除后可能无法恢复。仅本机删除不能清除地图供应商或托管服务商依法留存的日志。

8. 联系与主体披露

在线接收开启前将披露运营主体和隐私联系邮箱。当前运营状态及专用联系邮箱见下方；无法提供联系渠道时在线接收保持关闭。非敏感技术问题可通过 项目 GitHub 问题反馈报告不含个人信息的技术问题；请勿在公开问题区提交个人隐私或案件细节。隐私联系信息尚未配置，因此本站目前不会接收线上投稿。
